# Data-Driven Social Engagement Initiative

This project analyzes social media engagement patterns and provides recommendations for content strategy based on data-driven insights.

## Project Structure

- `01_Source_Code/` – Python modules for extraction, cleaning, analysis, modeling, statistical testing, recommendation logic, and visualizations.
- `02_Datasets/` – Data files for raw and processed datasets.
- `03_Charts/` – Generated charts and visual summaries.
- `04_Dashboard/` – Dashboard application.
- `05_Report/` – Final project report files.
- `06_Notebook/` – Jupyter notebooks for analysis.
- `07_Models_JSON/` – Model metrics and summary outputs.

## Getting Started

1. Create a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the pipeline:
   ```bash
   python main_pipeline.py
   ```
4. Launch the dashboard:
   ```bash
   python 04_Dashboard/app.py
   ```
